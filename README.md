# P3

Static website scaffold for the Dummy Model App.

## Files

- `index.html` - page structure
- `styles.css` - responsive visual styles
- `script.js` - sample model data + contact form demo behavior

## Run locally

Open `index.html` in your browser.

1. Commit and push this repository to GitHub.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, select:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (or your default branch), folder `/ (root)`
4. Save, then wait about 1-2 minutes.
5. Open the URL GitHub Pages gives you.
